# v1.8.6 Stage 1 与逐层报告开发实验

以修复后的 ResNet1D 五折为基线，复用已归档的五份原始运行配置。C1 新增 score 和 feature 两臂，每臂五折。首层无前驱，第二层起，目标局部分数加上紧邻前驱原始局部分数经 2 sigmoid − 1 变换的共享标量项。feature 另加前驱 128 维 token 的无偏线性投影。系数从零开始。训练、确切联合 MAP 推理和导出共用同一个头。C2 暂停。

使用项目环境并将 src 加入 PYTHONPATH。BASE_CONFIGS 指向原始五个 F*_resnet1d_nll_128_s23.json 的目录。单格命令如下，其余格将 F1 和 score 换为相应折与臂。JOBS 应在源码目录外，保留独立格目录。

```sh
python -m a3_ultrasound.v186 prepare "$BASE_CONFIGS" F1 score "$JOBS/F1_score"
CUDA_VISIBLE_DEVICES=0 python -m a3_ultrasound.v186 fit "$BASE_CONFIGS" F1 score "$JOBS/F1_score"
```

prepare 固定原配置哈希，fit 核验运行配置、目录内的抽样表和时间标定等输入。使用现有早停、余弦学习率和三套检查点。不同进程分配不同格目录，两张卡可独立工作。封存评价保持关闭。

PRED 指向已回传修复基线的 source 目录，含 F1 至 F5 的 predictions.jsonl。所有回放使用开发输入完整性校验，输出文件须使用新路径。

```sh
python -m a3_ultrasound.v186_replay c3 "$PRED" c3.json
python -m a3_ultrasound.v186_replay c1 "$PRED" c1.json --jobs "$JOBS"
python -m a3_ultrasound.v186_replay c1 "$PRED" c1_fixed15.json --jobs "$JOBS" --checkpoint fixed15
python -m a3_ultrasound.v186_replay c1 "$PRED" c1_last.json --jobs "$JOBS" --checkpoint last
```

C3 固定 10% 点级预算，均匀对照按结构有效层逐一枚举。C1 同检查点置换仅替换前驱特征贡献，按冻结基线源分数分箱，保留原 MAP 枚举及破同分约定。每板有支持的比率先在重复折内平均再跨板等权。开发集单种子结果用于决定是否继续。

## 相对声时读头的可选坐标

全波形独立读头默认使用 `model.relative_time_scale = "fixed80"`。在已有全波形、启用相对声时且无 reference bias 的配置中，设置 `model.relative_time_scale = "board_interval"` 可使用板级相邻标定声时间隔的中位数。流式加载器从冻结的有效界面声时导出每条 A 扫的 `board_interval_samples`，传入读头，参考中心偏移时分母固定。若使用预制 tensor batch，需随样本提供相同的浮点尺度。坐标选择仅影响读出计算；开发对照另行冻结编码器。
