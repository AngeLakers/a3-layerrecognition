# A3 v1.8.6 R1 详细实验计划

**版本状态（2026-11-28）**。R1 代码已在 `codex/v186-stage1` 分支，代码基准为 `0bcaf27`。冻结流式拟合、E1/E2 损失和 C3 历史回放均已实现。94 项相关测试通过，合成流式演练核对了四臂的参数更新、编码器冻结和权重来源。**真实新五折拟合尚待逐折匹配的第 15 轮编码器检查点。** 当前可报告的实证是历史开发结果和原五折 C3 回放。[R1 代码提交](https://github.com/AngeLakers/a3-layerrecognition/commit/0bcaf275582773f412c4a45ebc19fce33d64340e)

## 1. R1 要解答的问题

A3 用单条单通道、有符号的原始 RF A-scan 识别金属多层结构各界面的缺陷。在每个测点，模型按从浅到深的顺序输出 K 个有效界面的缺陷分数。当前试件为 K=2 或 K=3。状态串 `010` 和 `011` 的区别只在第三界面。C3 可以把某个位改为待判，例如 `10?`，保留其余位的自动判断。

| 研究环节 | R1 的问题 | 实验安排 |
|---|---|---|
| **WHAT · 界面读出** | 板间界面时差差别较大时，按板级界面间隔归一化，能否让声时坐标在跨板和参考时刻扰动下更稳定？ | 全波形 query 读出，单独比较 `fixed80` 与 `board_interval` |
| **HOW · 状态判别** | 冻结共同编码器后，重新分配易正常点和单重上游异常位的监督权重，能否净改善逐层判别？ | 五折比较 E0、EW、E1、E2，独立头作为统一结构 |
| **WHEN · 逐层报告** | 在有限复检预算下，应暂缓哪一层？首界面反射代理能否给当前置信度排序补充可用信息？ | 原 C3 为当前主策略，最深层、均匀与代理融合保留为历史对照 |

当前读取方式是由层序和归一化深度提供界面 query，在有效全波形的时序特征上读出，使用标定声时确定相对位置。骨干、query 映射和 C3 各自承担编码、读出和报告职责。历史 C1 前后两种上游交互方案已归档，C2 交换代价暂停。R1 的新增判别候选集中在轻量监督加权；冻结表征探针提供是否继续改分类头的证据。

## 2. 现有证据与 R1 的取舍

以下都是**历史开发结果**。校正回放含 200,010 条折内预测记录、15 个折板组合与 12 块实体。历史评估使用原五折、单个训练种子，开发板参与当时的检查点选择。去薄铝后的新五折需要重新建立同折 E0 参照。

| 历史结果 | 读数 | 对 R1 的意义 |
|---|---|---|
| v1.8.5 首轮普通 NLL 与修复基线 | 异常整组判对 **46.82% → 74.55%**。修复基线深层漏报 **12.71%**，正常点误报 **0.59%** | 首轮每折直接拟合骨干的板从 7–8 块缩至 3–4 块，恢复原训练分板后表现回升。板覆盖与训练步数同时变化。固定同一折来源和训练索引对 R1 尤其重要 |
| v1.8.6 C1 前置上游交互 | 真实特征较同板置换少漏 **9.26 个百分点**。真实特征较修复基线的异常整组判对为 **72.57% 对 74.55%**，正常误报 **0.78% 对 0.59%** | 已有证据说明模型使用同点上游信息。当前实现的净纠错不足以支持继续扩大结构 |
| 历史条件分类诊断 | 原始 RF 共享探针仅改 K=3 且 I2 初判阳性的点。原 12 块板回算异常整组 **74.55% → 75.28%**；按初判前缀分头为 **74.62%** | 单个真值状态对的收益方向不一致。继续验证目标表征和上游表征的独立增量，优先共享对照 |
| 原 C3 同点同层数 | 使用相同复检测点，每点暂缓一层。均匀选层每百复检点仍发出 **4.70** 个错误可靠层，原 C3 为 **2.41**，**11/12 块板**同向 | 保留原 C3。深层阳性直接报阳 **65.61% → 60.70%**，直接报阴 **7.90% → 4.94%**，待判 **26.49% → 34.36%**，厚2每百复检点错误层 **15.99 → 17.59**，单列此板 |
| R1 审查后校正的 C3 | 历史反射代理同点融合 **3.81**，重选点融合 **3.74**，仅代理重选 **3.23**。原 C3 为 **2.41**，口径均为每百复检点仍发出的错误可靠层 | 两种融合的全盘错误也高于原 C3。现有反射代理留作诊断，正式开发继续用原 C3 |

工程审核发现两处问题，均已在代码基准提交中修复。C3 改用等权分位秩计算模型分数与反射代理的融合优先级，历史逆抽样权重用于预算及计分。R1 的冻结训练入口限制在 v1.8.6 去薄铝协议，旧 v1.7.1 专用评价加载器也会拒绝带 R1 标记的检查点。独立代码审核给出了问题与复现。三路 Tken 外审在同一轮触及输出上限，四路记录为 `degraded`。修后的证据来自回归测试、合成流式演练及历史复算。

## 3. 新五折和冻结对照

|---|---:|---:|---:|---:|---:|
| F1 | 7 | 2 | 3 | 96,368 | 26,668 |
| F2 | 7 | 2 | 3 | 95,608 | 26,668 |
| F3 | 7 | 3 | 2 | 94,996 | 40,002 |
| F4 | 7 | 3 | 2 | 96,436 | 40,002 |
| F5 | 7 | 3 | 2 | 80,156 | 40,002 |

训练使用全部完整可靠异常点，每轮按每异常点 3 个正常点抽样。五折的训练索引和验证面板已经核验。未知标签保留可靠掩码，完整可靠的有效界面才参与主拟合和完整组合计分。验证估计采用现行逆抽样权重，按试件汇总。具体角色及哈希以 A3 归档分板清单为准。

### 3.2 权重、模型及运行设置

- 各折使用新分板上**预先指定的第 15 轮**编码器来源。核对源文件 SHA-256、对应折角色和模型结构，历史旧折角色有变化时以各自原折进行历史诊断。R1 只复用 `backbone` 与 `backbone_adapter`，设为 eval 并排除在优化器外。当前登记的是冻结对照方案，真实拟合按项目的运行授权执行。
- 四臂用同一个来源权重、同一 `seed=23`、同一初始化规则、批次顺序和训练索引。统一采用 `full_waveform`、`local_independent` 和 `stage1_donor=none`。只拟合 query、读头和独立分类头相关参数。HOW 采用 `fixed80`，声时尺度另设配对实验。
- 配置使用批量 16、至多 40 轮、两轮预热后余弦衰减，学习率从 0.001 衰减至 0.00001。参考声时共同扰动、验证选模和 MAP 决策沿用同一基线配置。正常误报护栏为**每折验证面板绝对 2%**。记录每格最佳合格检查点及未合格状态。实际验证指标仅作开发判断。
- 每格至少保存配置及哈希、编码器来源及哈希、各轮训练抽样索引、最优合格预测、训练曲线、分组支持、逐板结果和运行日志。分析前校验臂间分割与测点 ID 配对。缺失和未合格格单列，完整五折结论以齐全的配对格为准。

## 4. HOW · 四臂判别对照

五折各执行四臂，首批共 **20 格**、单种子。E0 和 EW 给出当前普通损失与简单正类加权参照。

| 臂 | `training.v185_loss` | 训练规则 | 要回答的问题 |
|---|---|---|---|
| **E0** | `nll` | 普通逐位 BCE，各点先除有效界面数再平均 | 新分板的同折开发基线 |
| **EW** | `weighted` | 对正类使用本折训练侧估计的逐层负/正计数比，沿用原加权 BCE 分母 | 简单正类加权在同一冻结表征下能到哪里 |
| **E1** | `easy_normal` | 只降权完整可靠且各界面全阴的记录，单点所有有效位使用同一权重 | 易判正常点的监督份额下降后，能否提高整组判对并控制误报 |
| **E2** | `single_upstream` | 对目标界面之前恰有一个阳性真值的目标位乘 1.5，目标位为阴或阳都适用 | 按浅至深的传播条件分配监督，能否改善单重上游组 |

### 4.1 权重的精确定义

令 `z[i,m]` 为目标位 logit，`p[i,m] = sigmoid(z[i,m])`。每条记录有 `K[i]` 个有效界面，padding 不计。训练时的可靠标签由数据清单固定。

- **E1** 对全阴点计算 `p_any = 1 - ∏(1 - p[i,m])`。乘积遍历该点有效界面。每个位的权重取 `0.5 + 0.5 × stop_gradient(p_any)`，范围 0.5–1。其余异常点所有位取 1。
- **E2** 依据每个目标界面**之前**的可靠阳性真值计数。恰一重时为 1.5，首层、零重和两重为 1。前缀计数用于训练权重和事后分组，推理依旧只由输入 RF 和已有结构读取信息。例子包括 `10` 与 `11` 的第二界面都加权。对 `110` 而言第二界面加权，第三界面的上游阳性数为 2，权重为 1。
- **归一化** E1/E2 均使用整批归一，分别对所有有效位累加 `w[i,m] × BCE[i,m] / K[i]` 与 `w[i,m] / K[i]`，两者相除。这样保留点级基础归一，权重在同一个 batch 中改变各点或各位的相对贡献。EW 保留旧口径，作为可复现的常规参照。

### 4.2 报告与入围判据

主表报告异常整组判对率、可靠全阴点误报率、深层可靠阳性漏报率、深层可靠阴性误报率、NLL 和 Brier。异常整组判对的分母是完整可靠的异常点，所有有效位同时正确才计成功。深层指第二层及以后。另分列 K=2/3、厚铝与 TC4，以及目标界面位置、目标真假和上游阳性数 0/1/2。保留每格分母、逐板差值、正向板数、持平和零支持。重复验证板先在板内平均，再按板等权汇总。

| 判据 | E1 | E2 |
|---|---|---|
| 整组判对 | 板均严格高于 E0，且超过半数有支持板改善 | 板均严格高于 E0 |
| 正常误报 | 每折合格检查点守住绝对 2% 护栏，板均误报不高于 E0 | 同 E1 |
| 目标组收益 | 结合整组判对与误报判断易正常点降权的整体收益 | 单重组深层阳性漏报下降、阴性误报不升，且超过半数有可靠阳性支持板漏报下降 |

通过的臂才考虑下一阶段。E1 和 E2 同时通过才考虑合并。结果如果只出现在个别板，报告收益随板变化。若进一步主张增益来自特定难度权重，应加入匹配总权重的对照。首轮属于五折单种子开发筛查。

## 5. WHAT · 相对声时尺度

两臂都保留全波形、相同 query、同一个折的冻结骨干、初始参数和 E0 损失。**在编码器的时序特征上重新执行读出**，因为历史已导出的界面表征已经包含旧坐标下的注意力汇聚。

| 选项 | 坐标 | 条件 |
|---|---|---|
| `fixed80` | `(t - τ_m) / 80` | 当前默认，可复用符合本计划全部设置的 E0 |
| `board_interval` | `(t - τ_m) / s_b` | `s_b` 为同板有效相邻界面标定时差的中位数。K=2 取唯一差值，K=3 取两差平均 |

有效界面标定时间应有限、严格递增。板上有效界面间隔来自既有冻结标定，估计相对位置时排除底波和 padding。两臂使用相同的全波形支持和无预设参考偏置。轻微移动参考中心时，`s_b` 保持固定。当前 TC4 板的相邻间隔约 175–235 采样点，厚铝约 576–577 点，那是板级界面时差。标定误差仍需以重复测量估计。

声时对照在同一开发测点上报告原标定、±8/±24 采样点的全层齐移及逐层单独移位。两类移位各占一半，幅度和方向在类内等权，逐层移位先在板内按有效目标层平均。两臂共用配对点与分母。越界或颠倒界面次序时单独记录受影响的板和点，覆盖不全时报告实际对照范围。

**继续条件**要求名义整组判对不降、正常误报不升，扰动下的板均深层漏报减少且等数错层率不增，深层漏报严格下降的板超过有支持板的一半。等数错层指阳性数相同但界面位置判错，分母为完整可靠的混合真值点。单列厚1、厚2和各 TC4 板。±8/±24 是预设压力测试，实际标定误差另用重复标定估计。若要进一步把增益归因于板间尺度，可以在训练侧预定共同除数作为对照。

若五折 E0 与上述设置逐项一致，声时试验只新增 **5 格**，每折增加一个 `board_interval` 臂。

## 6. WHEN · 原 C3 与复检对照

当前 C3 在每个点找出最小绝对 logit 的界面。点按该不确定性排序，在约 10% 的加权复检上限内取最长前缀。每个入选点只暂缓一层，未入选点及其余层的状态沿用初判。

**选择哪一层**与**选择哪些点**分成两个配对问题。

1. 固定原复检测点及每点一层，对比均匀选层的精确期望、固定最深层、原 C3 和同点融合。
2. 在相同 10% 加权上限及最长前缀规则下，比较原 C3、仅代理重排、代理融合重排。实际复检比例随末端权重可能有轻微差异，逐臂报告实际值。融合用模型不确定性与历史首界面反射代理的等权分位秩，原评价权重用于预算核算与统计。该代理为首界面 Hilbert 包络峰值与板级候选底波峰值中位数之比，I2、I3 获得相同的代理分量。

| 历史校正回放 | 实际复检 | 每百复检点仍发出错误层 | 每百全盘点仍发出错误层 |
|---|---:|---:|---:|
| 原 C3 | 9.9945% | **2.41** | **0.366** |
| 同点融合 | 9.9945% | 3.81 | 0.505 |
| 重选点融合 | 9.9945% | 3.74 | 0.567 |
| 仅反射风险重选 | 9.9939% | 3.23 | 0.699 |

每百复检点的错误以入选点加权数量为分母，分子只计实际发出的错误可靠层。全盘错误以全部开发点评价权重为分母。深层可靠阳性另分为直接报阳、直接报阴、待判三个互斥结果。新五折有对应预测后，沿同一评估定义复核原 C3。历史结果支持保留现有 C3。人工复检成功率和实际耗时仍待测量。

## 7. 执行顺序与依赖

| 顺序 | 工作项 | 格数和当前进度 |
|---|---|---|
| **R1-0 · 核对来源** | 对去薄铝新分板逐折核实第 15 轮冻结来源、权重哈希、数据索引和角色 | 分板和索引通过核验。匹配权重待落实 |
| **R1-2 · 判别** | 同时准备 E0/EW/E1/E2，按折成对对比并保留逐板数据 | 20 格。实现和本地验证完成，真实拟合待权重 |
| **R1-3 · 读出** | 固定 E0 配置，比较两种声时尺度 | 五折可配对，符合条件的 E0 可复用，共新增 5 格 |
| **R1-4 · 报告** | 用同一预算回放和逐板验证 C3 | 旧五折校正已完成；新五折依赖逐折初判预测 |
| **R1-1 · 并行诊断** | 取得原五折匹配的历史权重后，用冻结目标层表征和上游表征补完嵌套探针 | 核对纯重校准、仅上游软分数、目标表征、再加上游表征。可按有权重的历史折并行完成，并注明覆盖 |

冻结表征探针回答的是已有表征的可读信息，和 R1-2 的重新拟合属于不同实验。用于实际部署的探针输入仅使用冻结初判与表征。真实上游状态只用于分析分组或单列的理论参照。候选只有通过对应配对判据，才进入组合版本或确认实验。

## 8. 配置与复现入口

模型项目使用现有 Python 环境，将仓库的 `src` 加入 `PYTHONPATH`。R1-2 和 R1-3 从去薄铝的相应折开发配置派生，协议为 `A3-v1.8.6-no-thin`。在顶层填入 `r1_frozen_encoder`，其中 `checkpoint` 是该折第 15 轮权重路径，`sha256` 是权重哈希。恢复格式还需同目录 `resolved_config.json` 及其 `resolved_sha256`。EW 的 `layer_weights` 由本折训练侧支持给出。真实拟合沿用项目配置的授权开关。

```text
python scripts/a3_stream_run.py --mode train --config CONFIG --output RUN --fold F1 --head local_independent --seed 23
```

历史 C3 的 `PREDICTIONS` 指向 F1–F5 逐点预测父目录，`ARCHIVE` 指向含逐板 `*_all_features.npz` 和 `DELIVERY_MANIFEST.json` 的历史首界面风险档案。省略 `--archived-risk` 可回放均匀、固定最深层和原 C3。

```text
python -m a3_ultrasound.v186_r1_replay PREDICTIONS OUTPUT.json --archived-risk ARCHIVE
```
