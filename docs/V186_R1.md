# v1.8.6 R1 开发实验

R1 的当前证据来自历史开发预测的 C3 回放。容易全阴降权与单重上游加权已接入流式损失。现行去薄铝方案的配对拟合需要同折第 15 轮编码器检查点。

## HOW 配置

复制去薄铝后的 v1.8.6 开发配置（协议 `A3-v1.8.6-no-thin`），在顶层填入 `r1_frozen_encoder`，其中 `checkpoint` 为预定第 15 轮文件，`sha256` 为源哈希。恢复格式的检查点还需同目录 `resolved_config.json` 和其 `resolved_sha256`。共享初判的各臂用相同 checkpoint、seed、样本顺序和预测动作。加载器只复用骨干与输出适配器，训练初始时将两者从优化器排除并设为 eval。开发输出在 resolved config 和 summary 记录权重来源。

| 臂 | training.v185_loss | 值 |
|---|---|---|
| E0 | nll | 原独立 BCE |
| EW | weighted | 本折训练侧逐层负/正比例填入 layer_weights |
| E1 | easy_normal | 完整全阴记录按至少一层异常概率降权，最小 0.5 |
| E2 | single_upstream | 对上游恰有一个阳性真值的目标位乘 1.5 |

E1 和 E2 先把每个有效位的权重除以其有效界面数 K，再以整批的权重和归一。两种新损失使用流式冻结编码器入口。选用 full_waveform 与 local_independent，stage1_donor 为 none。真实训练仍由现有配置授权控制。

```text
python scripts/a3_stream_run.py --mode train --config CONFIG --output RUN --fold F1 --head local_independent --seed 23
```

## 历史 C3 CPU 回放

```text
python -m a3_ultrasound.v186_r1_replay PREDICTIONS OUTPUT.json --archived-risk ARCHIVE
```

PREDICTIONS 指向保存原 F1–F5 逐点预测的目录。ARCHIVE 指向历史首界面风险诊断归档，含逐板 `*_all_features.npz` 和 `DELIVERY_MANIFEST.json`。省略该参数可单独重跑均匀、最深层与原 C3。输出包含原复检测点上的配对对照、同预算上限下的重新选点与全盘错误。融合按折板计算等权中位秩，评估逆抽样权重只用于预算与计分。该回放使用历史抽样面板，其结果适用于该开发诊断。原界面分数与已报告的状态来自冻结模型。
